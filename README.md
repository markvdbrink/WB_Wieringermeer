# Repository code master thesis

This repository had the aim to store the code that I wrote for my [master thesis][https://repository.tudelft.nl/record/uuid:68709c9e-f720-4b96-acc4-e3837175bec4]. However, due to some unfortunate oversights at that time that code was lost. After finishing the thesis, we wrote a [scientific paper][https://doi.org/10.1016/j.wasman.2024.07.002] from its contents, for which I developed the code further. That code can be found at the [4TU data repository][https://data.4tu.nl/datasets/1900c71a-9980-4848-81bb-6815e4478b2c].
